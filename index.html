Selected work

Projects from my GitHub that show how I think about isolation, memory, and traffic.

PythonLinuxTLSJA3

TLS fingerprinting on network namespaces

A Linux lab with isolated red and blue hosts wired through two virtual routers. Capture a TLS handshake, then compute JA3 (client) and JA3S (server) fingerprints from the PCAP — no extra machines required.

CLinuxsbrk

Memory Allocator

Educational malloc / calloc / realloc / free on top of sbrk(). First-fit reuse, 16-byte headers, pthread locking, and optional LD_PRELOAD.

JavaSockets

Java socket server

Client–server over raw Java sockets: listen, accept, exchange a message, disconnect. A clean walkthrough of the request path before frameworks get in the way.

BashNmapTCP/IP

Nmap scan helper

Interactive Bash wrapper around Nmap: target, scan type, optional port range. Built for repeatable host discovery and port checks.

About

I like problems that force you to look at packets, heaps, and process tables instead of dashboards. Most of my public work is small, complete labs: isolate two hosts, allocate a block, accept a socket — then explain what actually happened.

When I fork something, it is usually to learn the floor of a stack: RISC-V bare metal, OS construction, or AI inference on Xilinx hardware.

  • C & Linux systems programming
  • Python for packet / TLS labs
  • Java sockets & concurrency basics
  • Bash, Nmap, and network namespaces
  • Memory management and allocators
  • JA3 / JA3S TLS fingerprinting
